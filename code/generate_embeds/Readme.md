
# Generate BERT Embeddings

This folder contains the code to generate BERT embeddings for the documents in the corpus.

## Input

Inputs to the code are title and abstract of the documents. The input file is a tsv file with the following columns:

- `PMID` - PubMed ID of the document
- `title` - Title of the document corresponding to the PMID
- `abstract` - Abstract of the document corresponding to the PMID

This will look like the following:

PMID | title | abstract
--- | --- | ---
123456 | Title of the document | Abstract of the document
234567 | Title of the document | Abstract of the document


## Execute script
To generate the embeddings, run the following command:

```bash
python run.py --data_path <path to the data folder>
              --save_path <path to the folder where the embeddings should be saved>
              --model_name <name of the model to use>
              --batch_size <batch size, default 64>
```

Arguments:
+ `data_path` - Path to the folder containing the input data. The input data should be a tsv file.
+ `save_path` - Path to the folder where the embeddings should be saved.
+ `model_name` - Name of the model to use. This should support most of the pretained models from the [transformers](https://huggingface.co/transformers/pretrained_models.html) library. Models used in this project can be found [here](https://github.com/zbmed-semtec/bert-embeddings-doc-relevance#models).
+ `batch_size` - Batch size to use. Default is 64. This is only relevant if GPU is available. (64 is a good default for a GPU with 4GB memory).

## Output

The embeddings will be saved in the `save_path` as a `pickle` file. This pickle file will contain a pandas dataframe with the following columns:

- `PMID` - PubMed ID of the document.
- `embedding` - Embedding generated by the BERT model corresponding to the PMID.
                Embeddings are numpy arrays.

This will look like the following:

PMID | embedding
--- | ---
123456 | [0.123, 0.456, 0.789, ...]
234567 | [0.123, 0.456, 0.789, ...]

## Requirements

The code supports Python 3.6 and above. The requirements are listed in the `requirements.txt` file. To install the requirements, run the following command:

```bash
pip install -r requirements.txt
```
